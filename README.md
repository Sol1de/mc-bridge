# mc-bridge

Minecraft façade for native code running inside the game's JVM (Windows x64, Java 21), built on
[jvm-link](https://github.com/Sol1de/jvm-link) and [mc-mappings](https://github.com/Sol1de/mc-mappings).

**Status:** API v1 catalog revised before implementation ([spec/api-v1.md](spec/api-v1.md));
implementation not started (tickets B2 onward). The catalog needs more symbols than mc-mappings
`data_version` 1 provides: see the prerequisites in the spec's appendix.
